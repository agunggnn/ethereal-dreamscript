# Image-generation prompts — Roblox Horror Myth Lab

## Global visual direction

Premium, collectible Roblox-inspired 3D avatar styling with layered accessories and a memorable silhouette; cinematic horror-game environments; deep blacks and graphite, electric-blue/cyan edge lighting, occasional amber practical light, restrained red danger lighting; crisp materials, high contrast with readable shadows, polished game-render finish. 16:9 landscape for story scenes; 1280×720 for thumbnails. Keep text out of generated images and add typography in editing.

## Required reference workflow

1. Generate and approve the canonical character turnaround first.
2. Save the approved master as `assets/character-reference.png`.
3. Attach that same master reference to every new scene and thumbnail generation.
4. Use the exact character lock prompt below; don't rely on text alone.
5. Reject any frame that changes identity-defining features. Do not silently repair a bad frame by changing the design.
6. Generated illustrations are inserts only; real gameplay footage must establish every myth result.

## Character lock prompt

“Use the attached master reference for RHM_INVESTIGATOR_01. Preserve the same Roblox block proportions, square head, messy black swept fringe with three distinct front tufts, small silver-blue three-prong floating crown, cool-blue face accents, premium black techwear hoodie/jacket with white zipper/drawstrings and blue piping, layered shoulder panels, asymmetrical utility straps, compact black backpack with cyan-lit core, charcoal cargo pants, black-and-white high-top sneakers, and the exact same cyan lantern. No redesign. Change only pose, expression, camera, environment, and lighting. Maintain the same face, silhouette, materials, accessories, and proportions.”

## Turnaround prompt

Create a polished reference sheet for RHM_INVESTIGATOR_01, an original Roblox-inspired premium block avatar. Show front, three-quarter, side and back views at identical scale, plus neutral/curious/shocked/confident face expressions. Fixed design: messy black swept fringe with three distinct tufts; small silver-blue floating three-prong crown; cool-blue face accents; premium black techwear jacket/hoodie with white zipper and drawstrings, electric-blue piping and layered shoulder panels; asymmetrical utility straps; compact black backpack with a cyan-lit core; charcoal cargo pants; black-and-white high-top sneakers; exact cyan lantern. Neutral gray-blue studio background, clean lighting, orthographic-style views, all accessories visible, no perspective distortion, no brand logos, no text except simple view labels. Every view must be the same character.

## Scene prompts

1. **Cold open:** RHM_INVESTIGATOR_01 with cyan lantern facing a distant generic red-eyed shadow in a ruined corridor, wide shot, strong leading lines, character face and premium outfit readable, no gore.
2. **Challenge reveal:** same character in three-quarter view beside a wall of ten mystery cards; cyan lantern and crown visible; leave negative space for title overlay.
3. **Verdict board:** same character gestures toward three blank green/red/amber result panels; clean readable layout, no baked-in words.
4. **Controlled experiment:** over-shoulder shot showing character testing one clear interaction in a dark generic horror environment; cinematic but uncluttered.
5. **Movement test illustration:** character cautiously moving through a corridor while a generic threat is distant; illustrative, not evidence.
6. **Hiding test illustration:** character crouched beside an alcove; same outfit and backpack, consistent corridor layout.
7. **Light clue illustration:** cyan lantern illuminates a subtle wall marking; generic visual metaphor only.
8. **Audio test illustration:** same avatar listening with focused expression in a dark hallway; optional sound-wave graphics added in editor.
9. **Midpoint reset:** character beside five tested cards; result tiles remain blank until evidence review.
10. **Results board:** wide shot of character beside ten empty result tiles, consistent palette and outfit.
11. **End screen:** character holding the same cyan lantern and gesturing toward two empty video-card spaces.

## Generation QA checklist

- [ ] Reference image attached and recorded in asset manifest.
- [ ] Hair, crown, face, jacket, backpack, lantern, pants and shoes match.
- [ ] Hands, limbs and block proportions are plausible and consistent.
- [ ] No accidental logos, random text, or extra accessories.
- [ ] Illustration is labeled as generated insert, not gameplay evidence.
- [ ] Save prompt, model, date, reference filename, scene ID and approval status.
